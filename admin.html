Help & Documentation

Getting Started

This admin panel makes it easy to edit your portfolio without touching code. All changes are saved to data files automatically.

Data Files Location

All your content is stored in the data/ folder:

  • personal-info.js - Your basic information
  • projects.js - All your projects
  • achievements.js - Awards and recognition
  • experience.js - Professional experience

Image Guidelines

For best results, use images with these specifications:

  • Project images: 800x600px
  • Profile image: 400x400px
  • Format: PNG or JPG
  • File size: Under 500KB

Responsive Design

Your portfolio automatically adapts to all devices. No additional configuration needed!

Publishing

After making changes, simply refresh your browser to see updates. For live deployment, push changes to your GitHub repository.
